## Core Patterns

- **Joint Attention Pairing**: Joint Attention Protocol: anchor all collaborative debugging claims to exact line numbers, commit SHAs, or test outputs.
- **Practical Application**: Collaborative debugging sessions and test failure walkthroughs.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
